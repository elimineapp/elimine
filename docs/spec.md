# Elimine: спецификация

## Принципы

1. Пользователь сам настраивает свои вещества: название, единицу, цвет, иконку, дозировки.
2. Приложение не комбайн: в нём нет ничего, в чём нужно долго разбираться.
3. Настройка это редкое разовое действие. Ежедневное действие это запись приёма в 2 тапа.
4. Приложение не поставляет встроенных веществ или пресетов, только инструменты для их создания.
5. Приёмы редкие: между ними дни, недели, месяцы. Аналитика смотрит на недели, месяцы, годы. Детализация внутри дня не нужна.

## Навигация

```
Главная ──тап по плитке──> Экран вещества ──⚙──> Редактирование вещества
   └──плитка «+ Новое»──> Создание вещества
Нижняя панель: [Главная] [Аналитика]
```

## Экран 1. Главная

- **Шапка:** название приложения, текущая дата. Позже здесь появится вход в общие настройки, когда они понадобятся.
- **Сетка плиток веществ** (2 в ряд). На плитке:
  - цветная контурная иконка;
  - название и единица;
  - последняя доза и когда: «250 мг · 12 дней назад», «сегодня», «вчера», «2 мес. назад»; если приёмов не было, «ещё не было».
- **Последняя плитка «+ Новое»** открывает создание вещества.
- **Блок «Последние»:** 10 последних записей по всем веществам (дата, вещество, доза). Свайп влево удаляет запись, snackbar «Отменить» возвращает её.

## Экран 2. Вещество (`/substance/:id`)

- **Шапка:** «Назад», иконка, название (единица), ⚙ (редактирование).
- **Время:** строка «Сейчас (сегодня, 14:35)». Тап по строке открывает выбор даты, затем выбор времени (так принято в Android: общего пикера нет).
  Чипы быстрого выбора: `Сейчас` · `Вчера` · `Позавчера`. У «Вчера» и «Позавчера» время по умолчанию равно текущему времени суток. Будущее время не допускается.
- **Доза:** чипы дозировок плюс `Своя` (ввод числа). По умолчанию выделена последняя использованная доза. Если её нет среди дозировок, она показывается отдельным чипом. Если приёмов ещё не было, выделена первая дозировка.
- **Кнопка «Зафиксировать».** После нажатия: вибрация, экран остаётся открытым, запись появляется первой в истории, snackbar «Отменить». Время возвращается к «Сейчас».
- **График** (итерация «Аналитика»): столбики, ось Y это сумма доз в единице вещества, пустые периоды видны. Масштабы: `2 нед` (по дням), `Месяц` (по дням), `Год` (среднесуточная доза по месяцам, делится на все дни месяца).
- **История:** все записи этого вещества, новые сверху, свайп влево удаляет.

## Экран 3. Создание и редактирование вещества

- Название (обязательно).
- Единица: свободный текст (обязательно) с чипами-подсказками `мг`, `г`, `мл`, `шт`, `таб`. Приложение ничего не пересчитывает. При смене единицы у вещества с историей предупреждение «История не пересчитывается».
- Цвет из готовой палитры, иконка из готового набора.
- Дозировки: список чисел, можно добавлять и удалять.
- В режиме редактирования: «В архив». Архивное вещество пропадает с главной, записи остаются.

## Экран 4. Аналитика (кросс-анализ, итерация «Аналитика»)

Задача: ретроспектива на длинных дистанциях, сопоставление веществ между собой и поиск связей между ними (например, одно вещество появляется после пика другого).

- Масштаб: `2 нед` и `Месяц` (шаг 1 день), `Год` (шаг 1 месяц), `Все годы` (шаг 1 год).
- Чипы-фильтры веществ по цвету, тап скрывает или показывает вещество.
- Накопительный столбчатый график: ось Y это число приёмов, сегменты по цветам веществ. Число приёмов, а не доза, потому что у веществ разные единицы, и складывать их нельзя.
- Метрики за период:
  - всего приёмов;
  - дней с приёмами (например, 22/30);
  - максимум приёмов за сутки и дата;
  - самый активный день недели или месяц;
  - доля каждого вещества в процентах от приёмов.

## Модель данных

```
substances  id, name, unit (текст), color (ключ палитры), icon (ключ набора),
            sort_order, archived_at, created_at
doses       id, substance_id, amount, sort_order
intakes     id, substance_id, amount, taken_at (UTC), tz_offset_min,
            created_at, updated_at, deleted_at
```

- ID это UUIDv7. Записи удаляются мягко (`deleted_at`), вещества архивируются.
- Единица хранится только у вещества. Дни для аналитики берутся в локальном времени на момент приёма (`taken_at + tz_offset_min`).

## Не делаем (сейчас)

Способ приёма, заметки, встроенный каталог, конвертация единиц, разовый приём без вещества, настраиваемое начало суток, детализация внутри дня.
